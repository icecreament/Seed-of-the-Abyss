# 壁垒蓄势反击（2026-10-22）

## 目标与取舍

上一目标回合为**progress**：追斩机会指示落地，原始完整检查34/35，旧演出观测夹具修正后单独17/17；去重后的534项与各份原记录保留在`reaver-opportunity-v1`。不是本轮结果，也不证明主观爽感已达成。

这轮转回守望者，完成一套与掠夺者不同的基础职业循环：**开壁垒承受减伤后的攻击 → 积蓄本次减免 → 松开、重按普攻反击**。不是照搬花伤口的贴身追猎，也不是新增互斥天赋树、第二套觉醒或全职业完成声明。

选择的是重装「承伤回击」，不是精确弹反：Q原先前200ms无敌仍不产蓄势，随后实际承伤才计算减免。保留原生命代价、技能冷却和无敌规则，不用无敌碰撞刷资源。目标「要玩起来很爽」继续保留，自动通关不能替代人工试玩。

## 规则

1. **必须由一次实际壁垒激活开启。** 开Q时记录本次基础攻击为反击加值上限；原1800ms壁垒、75%减伤、开盾175%震退、200ms起手保护和7000ms技能冷却不变。
2. 只有真正通过无敌检查并造成HP损失的受击，才可蓄势。额度为这次「无壁垒伤害（含护甲和最低1点）」减去「有壁垒伤害（同样含护甲和最低1点）」。不按入射次数、护甲原本挡掉的部分、免费无敌接触或虚构命中记账。
3. 本次蓄势最多等于开盾时基础攻击。每次有效减免刷新**1200ms战斗时间**机会；满额后再承受减免伤害可以刷新时间，但不增加上限。
4. 已消费的本次Q不再蓄势，必须下一次真实Q才能开启。未消费而过期的蓄势丢失；若仍处于本次壁垒内，后续真正的新受击可以重新积蓄。壁垒结束关闭收入，已经付出的机会仍可走完余下1200ms时钟。
5. **长按只继续原普通攻击，不消费蓄势。** 新按键／原140ms缓冲在原攻击冷却通过时，才把蓄势加到这一次普通挥击。空挥、背后、超距或被墙隔开仍花掉这一次，后续不迟到补伤。
6. 不自动靠近、不锁敌、不扩刀距／刀弧，不额外增加全周伤害。反击使用同一普通前弧，对原本这刀能打到的目标生效；反击实际命中额外检查当前视线。原非反击普攻规则不改。
7. 普通冲刺可以保留已付蓄势用于换位，时间照常流逝；冲刺无敌不能赚钱，冲刺中的普攻也不消费反击。原冲刺位移与体积不变。
8. 暂停冻结机会并隐藏操作标记；恢复重新显示，不自动出刀。三选一、换层、死亡／结算、销毁清空本次授权与预算，不能带进下一房间或死后兑现。

### 伤害账目

- 白板基础16，入射8：原壁垒扣2HP，积6；普通反击 **16+6=22**，暴击反击 **28+6=34**。加值不再乘一次暴击。
- 入射40：原壁垒扣10HP，减免30但只积到上限16；普通反击 **32**，暴击 **44**。露核1.25倍仍按同一次实际命中取整，分别 **40 / 55**。
- 高护甲已使8点来袭只掉1HP时，壁垒仍掉1HP，没有额外减免，不能蓄势。
- 蓄势事件不算攻击，不给吸血／击杀回血。真正反击仍按每名实际被命中的目标正常处理一次吸血／击杀收益，不虚构「6次格挡命中」。
- 荆冠原65%脉冲不花蓄势；破城骨槌震地仍是100%基础16，不继承反击加值。例：6点蓄势+骨槌，前方目标吃16震地+22普攻=38，后方只吃16震地，不额外绕背打反击。
