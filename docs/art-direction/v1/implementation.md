# 美术 V1：代码原生实现

2026-10-20。用户取消 API 图片生成，改为直接实现。未使用图像 API、API Key、外部素材或新增 npm 依赖。

> 后续更新：其余三个职业的外观、14 帧动作与肖像已补齐，见 professions.md；后续肖像 V2 见 portraits-v2.md。下文保留首轮守望者＋战斗 UI 的实施记录。

## 已实现

### 守望者

- 与当前技术一致的代码原生像素绘制，透明背景，最近邻放大。
- 骨白破损面甲、深色眼缝、木质寄生肩甲、暗紫披布、青绿胸核、缺口短剑。
- 战斗图集：32×32 单元，14 帧，脚底原点与碰撞体沿用现有实现。
- 0–3：行走；4–7：呼吸待机；8–11：挥剑；12：冲刺姿态；13：受击姿态。
- 四帧呼吸保持靴底锚点不漂移；挥剑含预备、挥出、跟随、收回。
- 角色动画按受击 → 冲刺 → 攻击 → 行走／待机的优先级播放，避免攻击被移动状态立即覆盖。
- 同步重绘 64×80 展示肖像，菜单与职业选择采用同一套外观标记。
- 维持现有左右翻转。此次未实现四方向或八方向独立素材，也未增加独立死亡动画。

### 战斗 UI 与视觉

- 左上：角色预览、生命数值、分段生命条、受伤缓退条、击杀数。
- 右上：楼层、存活时间、本层进度、暂停。进度仍来自现有时间／击杀规则，不新增经验机制。
- 下方中央：攻击／冲刺／职业技能槽，显示真实剩余冷却与就绪状态；技能名称随四职业切换。
- 左下：当前职业与寄生阶段。
- 低血量切换生命条与数值警示色，配合数值与分段结构，不单靠颜色识别。
- 根系镶边、石板切角、旧金属配色；共享按钮和菜单边缘也加入克制根系装饰。
- 战斗地砖降低噪点和明亮棋盘感；墙面边缘根系一次性烘焙，不增加逐帧绘制或碰撞体。
- 种子图标改为裂壳种子与下垂根须。

### 触屏

- 沿用摇杆、三个按钮的位置、命中半径、瞄准拖动与多指归属逻辑。
- 摇杆／按钮统一为暗色镶边，三个按钮增加真实冷却条。
- 触屏时隐藏 PC 技能卡与左下重复身份牌，不遮挡操作区。

## 未改变

职业基础数值、伤害公式、碰撞体、冲刺速度／持续时间、技能冷却、壁垒 75% 减伤、保存结构。
另外三个职业保留原来的角色素材与动作；本轮重点打磨守望者，并保证四职业均能使用新版 HUD。

## 本机运行注意

项目 .nvmrc 声明 Node 20.14.0。当前 PATH 上的旧 Node 不能解析 Vite 的现代语法，所以本轮使用 Codex 随附的 Node 24 完成启动、类型检查、构建和回归；未改动系统 Node 配置。
使用 Node 20+ 时可按原命令 npm run dev / npm run build / npm run test:regression 操作。
