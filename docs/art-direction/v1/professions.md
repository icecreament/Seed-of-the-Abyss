# 美术 V1 续作：补齐其余三个职业

日期：2026-10-20。接续 implementation.md 中的“寄生守望者＋战斗 UI”首轮改动。
本轮沿用代码原生像素制作，不使用图像 API、外部素材或新增游戏依赖；未重做已完成的战斗 HUD。

> 后续肖像优化：已接入 128×160 肖像 V2，保留原有界面显示尺寸；见 portraits-v2.md。本文为此前补齐职业动作的实施记录。

## 职业与外观

- **掠夺者 reaver**：破损铁面、暗红碎冠、侵蚀左肩甲、铁灰躯干与单手钩形重刃。替换早期战斗素材的裸胸／双骨刀，使战斗精灵与既有“巨刃·侵蚀”肖像及职业卡定位一致。
- **影行者 shade**：尖兜帽、深色脸部、青紫眼点、贴身皮甲、分叉披风、连接肩颈的飘带与双反握匕首。两臂跟随攻击方向，四段挥刺不再只播放移动帧。
- **棘语者 thorn**：暗绿皮甲、干藤冠、骨质面具、胸前种子与裂壳种子法杖。施法为蓄势→推杖→释放→收回；肖像同步增加面具、胸核、裂壳标记，旧箭袋改为携带种子的根系挎袋。
- 沿用旧版 64×80 全身肖像的站位构图，统一暗部和职业标志；菜单、职业选择和战斗 HUD 均读取同一组生产纹理。

## 动作与接入

四职业统一使用 **448×32 透明图集 / 14 个 32×32 单元**：

| 帧 | 内容 |
| --- | --- |
| 0–3 | 行走 |
| 4–7 | 呼吸待机；躯干活动，双靴落脚位置固定 |
| 8–11 | 四段近战挥击／远程施法 |
| 12 | 冲刺姿态 |
| 13 | 受击姿态 |

- Player 动画优先级统一为：死亡停止 → 受击 → 冲刺 → 攻击 → 行走／待机。移动更新不再立即覆盖其他职业的攻击动作。
- 普攻动作长度取 min(250ms, 当前普攻冷却)。掠夺者 250ms、影行者 240ms、棘语者 210ms；不改变实际伤害触发时机或攻击频率。
- 瞬时受击直接进入受击帧；影行者的暗影步直接进入冲刺帧，保留既有隐匿透明度、隐藏影子和破隐增伤逻辑。
- 重刃四段旋转均落在单元内部，避免图集裁边；三职业按守望者的脚底基准统一对齐；角色缩放、原点与碰撞体不变。
- 将多边形／线段栅格化提取为 PixelPrimitives.ts。已将运行时导出的守望者图集和肖像，与首轮 output/art-v1 中素材逐像素比较，RGBA 内容完全一致。

## 本轮主要文件

- src/assets/AbyssHeroes.ts：三职业战斗姿态与展示肖像。
- src/assets/PixelPrimitives.ts：整数像素多边形和线段。
- src/assets/ParasiticWarden.ts：仅复用公共栅格化方法，外观不变。

- src/entities/Player.ts：将守望者动作状态扩展到其余职业，保持原技能与数值。
- src/scenes/MenuScene.ts / ClassSelectScene.ts：移除“棘语者暂无肖像”的过时注释；保留防御性回退。
- scripts/check-regressions.cjs：增加 10 项生产像素／动画注册回归。
- scripts/check-hero-browser.cjs：可复跑的真实浏览器检查、运行时资产导出与截图。

## 未改变与边界

- 不修改四职业的基础生命、伤害、速度、攻击范围、攻击／冲刺／技能冷却、碰撞体或存档结构。
- 壁垒仍为 75% 减伤；血涌仍保留既有治疗和增伤；暗影步仍为隐匿冲刺及破隐增伤；荆棘新星仍发射原来的 8 向种子弹。
- 浏览器检查注入的 180ms 攻击冷却只验证动画对未来速度修正的兼容，不会写入职业配置或真实存档。
- 仍为左右翻转，不新增四方向／八方向素材，不新增专用死亡动画。
- 本轮不重新打包 APK／EXE；触屏检查是浏览器模拟，不等同于安卓／iOS 真机测试。

### 复跑

先用 Node 20+ 启动项目开发服务，执行常规类型检查、构建与回归：

```text
npm run dev
npm run build
npm run test:regression
```

浏览器检查不安装依赖。如果本机已有 Playwright，可执行：

```text
node scripts/check-hero-browser.cjs
```

若 Playwright 由外部工具运行时提供，将环境变量 PLAYWRIGHT_MODULE 指向其包目录；可选 EDGE_EXECUTABLE 指定 Edge 可执行文件，SEED_TEST_URL 指定本机开发服务，SEED_ART_OUTPUT 指定输出目录。默认使用全新隔离浏览器上下文，不读取系统浏览器资料或用户存档。
