# 肖像 V2：更强的职业气势

日期：2026-10-20。用户重点希望肖像“更帅”，本轮以剪影、姿态和职业辨识度为主，不只增加小细节。

## 已接入的变化

- **守望者**：收窄并压低骨质头盔，强调封闭面甲；扩展干枯寄生肩冠、根系手臂与破损披布。通过肩甲／头盔比例和胸核护甲形成沉重骑士感。
- **掠夺者**：前探的铁面、折损红冠、侵蚀肩甲、错落站姿与更长的缺口重刃；血色主要沿甲缝和布料使用，不做通体红色发光。
- **影行者**：一高一低的双刃戒备姿态、更窄的兜帽、遮住一侧眼睛的帽檐、向后延伸的斜披风。匕首使用冷灰钢刃，紫色保留给布料和饰扣。
- **棘语者**：狭长的开缝骨面，去掉旧版近似笑脸的嘴部／脸颊轮廓；分叉干藤冠、木质肩甲、携种挎袋与裂壳种子法杖，强调荆棘祭司感。

## 展示与素材规格

- 独立模块 src/assets/HeroPortraits.ts，四张原生 **128×160** 透明像素肖像，不是把旧图简单放大。
- 以 64×80 设计坐标构图，半格坐标生成原生单像素的刀刃、眼缝、面甲裂口和材质边缘。
- 菜单缩放 1，显示占位仍为 128×160；职业卡缩放 1.5，显示占位仍为 192×240。
- 靴底统一位于原生 y148–149，界面中的脚底位置、基座和按钮命中区域不变。
- 保留整数像素填充、最近邻过滤；生产肖像 alpha 只有 0 和 255，不使用柔边抗锯齿或模糊光晕。
- ParasiticWarden.ts / AbyssHeroes.ts 继续导出原来的肖像绘制函数名，具体绘制转到新的展示模块。

## 未改变
