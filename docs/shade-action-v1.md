# 影行者：双刃切入与护刃回身 · action v1

## 这轮要解决的体验

肖像已经是低重心、双匕、藏脸的刺客，战斗身体不能还像直立挥手。围绕已有的「破隐攻击 → 实际命中取得回身 → 无方向冲刺撤开」规则，补上身体姿态，而不是新增伤害、位移或发光层。

- 破隐攻击：四格贴身切入、双刃交错、聚拢、收回护势。真正改变躯干、腿部与握刃位置，不只换刀光。
- 实际回身：两格低姿护刃撤步，围巾跟随撤离方向；仅在原逻辑确实选择无移动输入的反向冲刺时出现。
- 基础与觉醒各自绘制；不把觉醒装饰画成第三把悬浮匕首，32×32 原生边界、脚底锚点和最近邻过滤保留。
- 新动作来自四张独立小图集。原 27 张图集的全幅 RGBA 应保持不变，普通动作、肖像和其他职业不重画。

## 三个状态必须区分

1. **攻击承诺**：原 tryAttack 真正接受攻击并消耗隐身，才开始四格切入。空挥、只打碎弹体也可以播放，因为玩家确实出刀；这不是「已经命中」提示。
2. **命中确认**：仍由原 RunScene 的实际基础攻击目标 HP 损失调用原 ShadeReturn.confirmHit。姿态读数、空挥、破弹都不能发放回身。
3. **回身使用**：原 performDash 消耗真实回身机会，且移动意图长度平方不大于 0.01、确实走反向 fallback 时，才出现两格回身身体。有方向输入继续听玩家的，用原普通冲刺身体，不用倒退姿态冒充。

攻击承诺不等于命中；拿到机会不等于已撤步。动作不能替玩家按键，也不能把原本未命中的攻击补成命中。

## 时钟、优先级与取消

- 切入读取已有 attackPoseTimer，初始 duration 记录本次真实攻击期限，不另推进时钟；普通攻击 240ms，更快的攻击也按实际期限映射，不强制播满。
- 回身读取原普通 dashTimer（140ms），没有追加「姿态无敌」或撤步位移。
- 原基础伤害 15、破隐伤害 33、原回身资格 650ms、普通冲刺速度 520、冷却 600ms 不变。原 Q 的技能冲刺 160ms、无敌 400ms 也不变；若紧接 Q 回身，可能还有原 Q 无敌剩余，不能误称是新增回身保护。
- 回身期间接受原普通攻击，不截断原冲刺身体或重开冲刺计时；短暂受伤画面优先，但底层原攻击/冲刺时钟照常推进。
- 被冷却拒绝的攻击、被无敌拒绝的受伤不凭空取消或重启动作。新 Q、新冲刺、真实受伤以及原清理路径接管动作；突变选择、换层、死亡和停战不残留上一段姿态。
- 普通暂停、原命中停顿都冻结原时钟，不用墙钟播放。觉醒切换保留同一格和期限。
- 舒适模式/减少动态效果恢复原动作；中途关闭也回到原攻击进度或原冲刺，不从头重播。

## 改动范围与既有失败

生产变化限于 Player 的接入与清理、姿态映射、影行者身体绘制和图集注册。原 RunScene、ShadeReturn、ReaverPursuit 整文件保持上轮快照字节；原字段声明和其余 Player 成员由源码范围审计核对。

三个自然局脚本只扩展姿态可见性断言与只读观测；注册的逆替换能恢复完整原策略。没有改敌人、突变偏好、输入评分或为凑动作覆盖改控制器。影行者使用已存在的「读取已渲染回身提示 → 松移动 → 后续看到无方向提示再按 Shift」策略，不是这轮新增自动回身。

探索 `checks-01` 中的一项失败来自检查把原攻击正常产生的两个 FX 也当作身体对象增长；保留失败文件。之后将这项断言改为核对身体显示/数值/监听器，原子对象计数保留在原始证据中，另有 500 次动作循环的完整对象/监听无增长断言。没有为此改生产机制。

历史守望者主套件 40/41（原自然策略未覆盖付费反击）与掠夺者主套件 42/44（原录帧 helper 两门超时）均不覆盖、不改绿。本轮沿用独立输入确认版掠夺者捕获作为当前源码兼容检查，不把它冒充旧失败的原样重跑通过。
