# 精英破招与反打窗口（2026-10-21）

> 历史阶段记录：普通怪的近身出手和根槌追击接触规则已在 `docs/melee-intent-v1.md` 更新；本文原阶段结果与证据保留，不作为当前生产规则说明。


## 目的与本轮范围

在四职业觉醒之后，补一个值得主动抢攻、躲招和反打的对手：**第三层的根槌精英**。不是单纯提高精英数值，也不是所有敌人一起套新招式。普通重锤、爬行怪、喷吐怪及其另外两种精英保持原行为；章节 Boss 继续使用原本的三招和 +35% 暴露规则。

## 一个完整的交战节奏

1. **出场**：第三层第一波用一个名额替换成根槌精英，总怪数仍为 7，而不是额外增加。沿用 240–460 的离玩家生成环与 450ms 出场保护。
2. **接近**：首次可行动后的 700ms 内不发动招式；必须有视线、目标不隐身、距离不超过 130 才开始蓄力。
3. **蓄力 1050ms**：重锤扎根，固定自身位置，地面显示真实 **94 半径**的砸地范围、逐步填满的时间弧线，以及「攻击破招 当前伤害/所需伤害」。播一个短促低频蓄力提示音。
4. **二选一应对**：
   - 持续抢攻，在这一轮蓄力内累计造成 `max(20, ceil(最大生命 × 16%))` 的有效伤害，可破招。第三层原属性 160HP 的精英需 26 伤害，四职业无技能/突变的普通攻击都能完成。
   - 或直接走出范围 / 用冲刺无敌躲过砸地。预警不追人，也不隔墙扣血。
5. **反打**：破招露核 1250ms；未打断的砸地结束后也露核 900ms。期间停步、无接触伤害、受到伤害 +25%。不是只有高手打断才有反击机会。
6. **恢复**：再经过完整 2400ms 的出招冷却才可开始下一次蓄力；恢复追击时才恢复接触伤害。

蓄力期间同样没有接触伤害，避免玩家按提示贴近破招却被碰瓷。扎根和露核期间免疫击退，不能靠每一刀推走危险圈或用击退无限延长预警。其余时间仍用原来的移动与击退逻辑。

## 公平性与反馈

- 原基础最大生命、伤害、速度、碰撞、击杀治疗/收益不变。砸地只用一次原精英伤害，不另加隐藏伤害倍率。
- 危险范围与实际中心距离判定一致：94 内判定，94.1 外不判定，不另加看不见的玩家半径。
- 原始接触/冲刺/受击保护、守望者壁垒减伤正常生效；影行者的隐身不是区域攻击无敌。
- 墙体视线在落地时再次校验；诱饵不被当作真实 Player 扣血。已承诺的地面范围不会因目标隐身、移动或更换诱饵而追踪。
- 打断只取消本次砸地、开启反打窗口，并有局部碎光、破招文字、合成破碎音和 40ms 封顶顿帧。没有额外直接伤害、回血、击杀或技能返还。
- 触发破招的那一下按原伤害结算；**之后的命中**才享受 +25%。仍按有效伤害统计伤害与吸血，过量伤害不计收益。
- 致死命中优先：杀死正在蓄力的精英不会再播放破招、排队砸地或重复发奖励。
- 露核使用独立的开裂胸甲/金色核心像素纹理，不只改全身染色。五种职业/觉醒材质不受影响。
- 中文/英文状态文字有 3px 深色描边，生命条、压制条和状态文字分层；预警边缘触及战斗 HUD 时也会触发原有让位，不仅保护精灵身体。
- 同场最多一只根槌精英。后续随机到同类精英时降为普通重锤，不增加招式同时出现的密度；另外两种原精英不受此上限影响。
- 结算显示实际「精英破招」次数；没有新存档字段、永久数值或额外货币奖励，旧 RunMetrics 调用缺省兼容。

## 时间与生命周期

所有倒计时只由战斗 delta 推进。暂停、三选一、顿帧冻结期间不推进预警、压制或露核。长帧一帧最多改变一个阶段，不能在同一帧开始预警又落地命中，也不会跳过刚出现的反打窗口。击杀、切层清场与场景销毁取消排队事件并销毁提示对象。

## 实现位置

- `src/systems/EliteDuel.ts`：无 Phaser 依赖的蓄力/打断/暴露/冷却状态机与有上限事件队列。
- `src/entities/Enemy.ts`：仅精英重锤拥有状态机，负责扎根、实际受击压制、提示与开裂纹理、清理。
- `src/scenes/RunScene.ts`：真实伤害链路、砸地范围/墙体判定、局部反馈、生成名额/数量限制、HUD 让位、运行统计。
- `src/assets/PixelFactory.ts`：开裂胸甲纹理与明确的编号帧。
- `src/systems/CombatAudio.ts`：原创低频三脉冲蓄力声音；沿用静音、暂停、声部上限与生命周期。
- `src/scenes/DeathScene.ts`、`src/systems/RunState.ts`：可选的破招结算记录，不改变永久存档结构。

- `npm run test:elite:browser`：19 项实际引擎检查，含四职业真实白板攻击破招、真实移动+SHIFT闪避、故意不躲确实受伤、半径边界、墙体、无敌、接触、诱饵、暂停、三选一、生成上限、双语、HUD、触屏按住攻击、结算和重开。
- `npm run test:chapter:natural`：仍为新存档、正常速度、只发送实际输入的全章控制器。增加只读精英状态观测，将可见地面预警加入避险策略；不改角色位置、属性、敌人、随机数、计时或伤害。

证据目录：`output/elite-v1/`。机制夹具截图与自然全章截图/录像分开标记；不能把夹具里的摆位和预警测试冒充自然流程。

## 未完成的验收

一只可破招精英不代表所有精英已有不同招式，也不代表整章敌人编排、四职业平衡、真实触屏手感或主观爽感已经完成。本轮不引入第二章或新职业；后续应根据实际伤害来源、自然破招机会和人工试玩反馈决定继续调整什么。

2026-10-21 完成完整复验：类型检查、生产构建成功；**329 项检查通过**。包含原有 298 项、新增精英模型 12 项与精英浏览器 19 项。原手感模型仍为 11 个检查组，但音色范围扩充为 12 类 × 4 职业。构建仍有原有的包体积提示，没有把该提示当作测试失败或声称已完成包体优化。
