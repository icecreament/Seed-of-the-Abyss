# 棘语者：看得懂、敢按 Q 的远程引爆 · cue v1

日期：2026-10-24。全局目标仍是「要玩起来很爽」，本轮不是新增技能或改平衡，而是把已经存在的可兑现机会接回实际操作界面。

## 从现有断层出发

上一轮新增了由实际种子伤害触发的收掌施法，但技能卡仍固定显示「荆棘新星 / 就绪」。旧近身保命策略在一个自然样本中取得植种后没有再按 Q，导致获胜却没有覆盖引爆动作；另一条明确声明的「看真实满种 HUD 按 Q」策略则能兑现。这只能说明提示与行为之间值得继续打磨，不是首次游玩的人类可发现性结论。

本轮动手前核对上一轮补充样本冻结的 147 份文件，全部无漂移；保存本轮六份改前源文件的原始字节与 SHA256。`before/ripe-desktop.png` 和 `before/state.json` 来自真实引擎 POST_RENDER：角色与第三层普通重怪距离 500px，预置真实三层种子记录，原卡仍是泛用图形和「荆棘新星 / 就绪」。这是受控场景，不冒称自然植种录像，也不把 500px 说成屏外。

## 做了什么

### 信息随真实机会变化

| 实际状态 | Q 技能卡 | 强调 |
|---|---|---|
| 未解锁寄生花冢，或没有有效植种目标 | 原「荆棘新星 / Thorn Nova」 | 原图形和冷却信息 |
| 有植种目标、没有满种目标、技能就绪 | 「远程引爆 / Detonate」＋植种目标数 | 闭合种荚、浅绿，不冒称满种 |
| 确有满种目标、技能就绪 | 同上，显示实际满种目标数 | 裂开的种荚与金色文字 |
| 有种、但技能冷却中 | 仍说明能远程引爆，状态显示实际倒计时 | 灰化种荚，不显示金色就绪 |
| 真实引爆后已无种 | 回到原新星名称与实际剩余冷却 | 不遗留满种机会 |
| 暂停、选突变、换层、死亡结算 | 撤掉机会和可用状态 | 不遗留高亮 |

顶部保留既有 `植种 N · 满种 N · Q 引爆` 前缀，追加「无需靠近 / Any distance」。已有 UI 引导策略与触屏 `技能键 引爆` 语义保持兼容，不通过改控制器规则制造覆盖。

触屏按钮同步显示动作名称；无种时准确恢复原「技 / SKL」。复用按钮原有 Text，不增加对象、命中区域、监听或动作。名称限制在 64px 内，仍保留原来的冷却条。

### 原生图形，不靠更多遮挡

`RootFrame.ts` 新增一个种荚图形。闭合/裂开仅说明是否确有满种目标，**不是把多只敌人的总种层拼成三格进度**。只有「实际可用＋至少一只满种」才金色；冷却时有满种也不闪金。

复用原 Graphics，通过状态键缓存重绘；名称/状态只在实际改变时更新。不重置 alpha，原 HUD 避让仍拥有透明度控制。其他职业的原技能图形、名称和输入维持不变。

### 不修改玩法

- 新增 `ThornBloomCue.ts`，只读实际解锁、有效目标汇总、冷却与角色状态；非法冷却不广告就绪。
- 有一层就能引爆，满种不是新增的释放门槛。
- 不添加距离、屏幕或视线过滤。原有墙后/远处种子全局结算仍成立。
- 不自动放技能，不额外植种/消费种子，不改伤害、冷却、范围、动作优先级或原新星近身效果与八向弹。
- `bloomSummary` 原返回形状和原规则源文件不变；其余三个职业提示分支不改语义。
- 寄生花冢突变说明补充「每个目标最多三层、无需靠近」，中英对应。

## 从真实画面发现并修正的边界

触屏英文说明最初扩写到五行，真实卡片中顶到了觉醒徽记。没有放松边界断言或缩小整套选卡 UI：把说明写成保留全部规则的短句，18px 下三行、70px 高；与觉醒徽记、选择按钮保留实际间隙。四种语言/设备组合均有实际截图和边界记录。

探索检查中的两个夹具错误也保留：第一次误把原「技」写成「技能」断言；随后仅写 `hp=0` 并不会改变 Enemy 的 alive 状态，改为实际 `takeDamage` 形成死亡。它们不是生产玩法修复，也不把探索轮次的通过数累计成最终测试数。真正的英文触屏重叠在 `checks-04` 保留，修正文案后才进入正式冻结运行。
