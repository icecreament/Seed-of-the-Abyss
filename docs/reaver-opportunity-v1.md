# 掠夺者机会指示与操作台阶（2026-10-22）

## 承接的证据与目标

上一轮血棘机制能在真实键鼠夹具中使用，512项机制检查通过、原控制器四职业整章4/4；但血棘优先独立自然局虽获胜，伤口付费追斩0次，覆盖门禁失败。另一条环斩优先局出现1次。保留这份32/33历史，不以新版本随机胜利重写。

这轮不先加伤害、自动追踪、扩大范围或保证突变掉落，而是补足**玩家看见目标、知道下一步操作**的战斗UI。它只改变提示，不能直接证明主观爽感或真实玩家的使用率上升，也没有修复/取消上一轮自然覆盖失败。

上一目标回合分类：**progress**——正式回归终止、保留自然覆盖失败并产生了当前改进依据。本回合继续修改生产实现，而非重述计划。

## 当前行为

- 提取`findReaverPursuitChoice`，实际追斩与本地目标提示共享同一个只读选择器。
- 正常选择继续使用原移动、瞄准、刀内敌人优先、视线、距离、目标存活／出场状态、击杀票或未来流血脉冲。提交前仍要求原攻击冷却结束、新按键和正常生命周期。
- 引导选择仅假设「朝这名候选移动」来找出可提示的目标；不改实际移动／朝向，不授权攻击，不消费流血、不增加击杀票。实际静止／后退按键仍是原空挥。
- 五个台阶：
  1. **松开**：仍在长按，提醒先松开再按。
  2. **移动**：目标可追但当前移动不合格，提醒朝目标移动。
  3. **收刀**：方向合格但攻击仍在原冷却中，不冒称已就绪。
  4. **已接招**：已有方向合格的新按键缓冲，告诉玩家保持向前，不再要求额外补按。
  5. **就绪**：已松开、方向与目标合格且无攻击冷却，提示重按追入。
- 来源前缀区分血棘伤口与击杀追斩。正在追入时继续原「撕裂追斩／追斩」状态。
- 候选旁为一对开放缺口，不画填充锁定圈或贯穿地面的长线；只有已对齐的就绪／缓冲态才画短小落点箭头。提示不意味着安全，更不授予无敌，精英危险圈继续原样显示。
- 无相关目标时不再常驻血棘长说明；击杀票保留轻量待机文字。墙后、过远、背后、已有刀内目标和耗尽伤口不会被标成就绪。
- 暂停时隐藏操作提示、但不取消已付伤口预约；恢复重新计算。三选一、换层、结算立即清理，重开销毁旧图形。
- 提示文字只在内容／颜色变化时重绘Canvas，固定状态的1000次提示更新不重新栅格化；一个复用Graphics，动态命令不随帧数累积。

### 正式检查中的旧演出夹具问题（尚未改动冻结脚本）
