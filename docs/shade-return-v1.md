# 影行者：命中后回身 v1

## 本轮动机与实际基线

目标不是增加一次冲刺、伤害或无敌，而是把「切入—破隐命中—脱离」接成一套容易操作的动作。

修改前已在真实键鼠受控场景复现：Q 切入落地，空格命中 33 点，攻击冷却 240ms、普通冲刺已就绪；没有移动方向时按 Shift，速度仍为 `(520,0)`，与切入同向。问题不是攻击后摇禁止冲刺，而是原地冲刺默认沿瞄准朝向，容易重新冲进刚打过的敌人。

基线产物：`output/shade-return-v1/baseline-play/baseline.json`、`forward-dash.png`。固定敌人血量和速度、禁用刷新，仅用于行为诊断，不是自然实战。

## 新规则

- 只有真正消耗隐身的普通攻击、且通过原命中解析造成敌人实际 HP 下降，才获得 **650ms 战斗时间**的回身方向窗口。
- 下一次**原有普通冲刺**，没有方向输入时沿该次首刀的反方向冲刺。后续鼠标朝向不会改变已经存下的回身方向。
- **方向输入永远优先**：玩家要向任意八方向冲刺，仍完全听玩家的。
- 不新增冲刺次数，不返还冷却。原 **600ms 冷却、140ms 持续、520 速度**不变；原位移预算、墙体碰撞和无敌时间不变。
- 实际执行一次普通冲刺才消费窗口，带方向的普通冲刺也会消费；冷却未好不会空耗窗口。
- 空挥、普通非破隐命中、只击碎敌弹均不授权。一次多目标命中只授权一次，不刷新计时。
- 新 Q、实际受伤、选择突变、换层、死亡、结算与销毁清理窗口；暂停和打击停顿冻结战斗时间。
- 现有按住攻击等待有效破隐机会的规则保留，不把提示变成自动追踪或自动战斗。

## 展示

- 命中后只加一次局部短交叉刃，不叠新震屏、闪屏或声音。
- 脚边开放式双折箭显示下一次实际普通冲刺的方向；有方向输入就显示玩家方向，否则显示存下的反向。
- 复用职业行动提示：键鼠显示 Shift，触屏显示冲刺键；区分冲刺尚未就绪与可回身。
- 指示只是方向提示，**不是安全路线承诺**。背后有墙照常撞墙，背后有危险仍需玩家判断。

## 改动与边界

生产：新增 `src/systems/ShadeReturn.ts`；接入 `Player.ts`、`RunScene.ts`、`CombatPresentation.ts` 与中英文 `i18n.ts`。`package.json` 注册三个检查入口。原攻击数值、命中判定、范围伤害和其他职业机制没有为回身改写。

`output/shade-return-v1/milestone.patch` 与 `milestone-provenance.json` 记录相对本轮已保存基线的增量，不以整个脏工作区冒充本轮修改。没有提交、回滚、清理用户原工作。

## 已完成的专项验证

- 纯模型 **10/10**：命中授权、一次性消费、650ms 边界、不可变反向、失效与取消、方向样本；一万方向样本只计一个检查。
- 第二次专项浏览器 **17/17**：真实引擎命中、位移预算、八方向优先、冷却与缓冲、无敌、碰撞、暂停、生命周期、显示只读、四档倍率、中英文、其他职业隔离、真实键鼠与模拟触屏。
- 键鼠实录：Q 切入 → 实际 33 伤害 → 零方向 Shift 反向撤离，仍只有一次原普通冲刺。
- 第一次独立自然样本 `natural-01`：新存档、正常时钟、正常刷新、只用真实键鼠，**106.223 秒战斗时间胜利**；三突变、自然觉醒与精英均覆盖。**16 次实际命中授权、16 次实际渲染提示、13 次零方向反向冲刺**，后者均为原 600ms 冷却与 140ms 持续。

### 自然策略声明

新增 `scripts/check-shade-return-natural.cjs` 派生于原整章控制器，但不是原控制器：只在已渲染的有效回身提示出现后，以真实 key-up 松开方向；后续轮询确认画面已在零方向状态渲染、普通冲刺就绪，才按 Shift。其他时候沿用原接近、瞄准、Q、避险冲刺、按住攻击与选突变策略。

只读观察器逐一前传原方法一次并保留返回值，记录实际破隐、原命中 HP 下降、授权、渲染与执行冲刺。没有写移动意图、位置、HP、数值、冷却、时钟或刷怪。保留原控制器的胜利、三突变、觉醒与精英门槛，再增加实际命中授权、实际可见提示及实际零方向反向冲刺门槛。不与原四职业策略、其他独立策略混池，不重抽自然局覆盖失败。

### 保留的失败与修正

第一轮专项 `checks-01` 在第十项撞墙夹具中停止：硬编码错误地假定最多能走 20 像素，实际身体到墙的初始间隙为 32 像素；实际结果正好是 `playerLeft == wallRight`，并未穿墙。只修正夹具：从实际 body 边界测初始间隙，严格验证最终位移等于该间隙、边界相等、纵向不动、原冷却不变。没有为通过测试修改生产碰撞，也未删除原失败。后续七项在首轮没有执行，不计成首轮通过。

实现过程曾在严格替换数量及英文技能名不匹配处中断。检查了实际落盘内容后只补缺失的文案和格式，没有重跑可能重复应用的实现脚本。

前轮影行者第三层死亡、旧守望者胜利但零反击覆盖、旧血棘胜利但零伤口兑现等历史失败保持原样；上一轮 47 门全通过也不能擦除它们。
