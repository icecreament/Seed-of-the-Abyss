# 四职业肖像与选中演出 · presence v1

## 目标与方向

在已有原生像素美术上强化「更帅、有气场、职业轮廓一眼可辨」，不靠全身发光或满屏粒子。仍使用代码绘制的 128×160 透明肖像，不引入外部素材、运行时图片依赖或新生成器。战斗 32×32 单元、碰撞、数值、技能、输入与存档语义不因这轮美术改动而改变。

| 职业 | 本轮肖像变化 |
|---|---|
| 守望者 | 骨盔收为高眉、黑色眼缝和长下颌，树根肩甲改为破碎尖缘；剑从举持改为垂剑镇守，重心保持稳定。 |
| 掠夺者 | 前探喙形铁面、破损铁冠、感染肩甲尖缘；放宽处刑巨刃的暗色刀脊与切削面，不把武器做成发光棒。 |
| 影行者 | 重画低重心双匕姿态：后腿伸展、前膝弯曲、躯干斜向蓄势，围巾与分裂披风向后拖，藏脸只留一道冷色眼缝。 |
| 棘语者 | 保留实际项目的种核法杖，不改成普通弓手。改为非对称托种施法，偏转站姿、长喙骨面、分叉棘冠与倾斜杖身，避免绿色重甲骑士的重复轮廓。 |

## 觉醒适配

基础肖像变化后，旧觉醒前景会遮掉新的骨面和眼缝；尤其棘语者旧前景大种核直接盖住脸。因此同步重画四职业觉醒肖像叠层，扩展向外的树根/感染/披风/棘冠轮廓，将头饰约束在额部以上，保留面部焦点。

`drawAwakenedHero` 战斗图集绘制函数文本保持不变，只替换 `drawAwakenedPortrait`。新浏览器检查还对实际生成的八套基础/觉醒战斗图集做 RGBA SHA256 对比，全部与修改前捕获值相同。PNG 编码字节不作为像素相等的替代。

四套基础/觉醒核心面部区域逐像素相同，原透明边距、靴底 y148–149 和图集分辨率均保留；同时人工检查了实际生成的基础/觉醒拼图。这不等于主观审美已经被自动验收。

## 选择页演出

- 原相同圆环替换为四种稀疏纹章：守望者残盾、掠夺者斜向刃痕、影行者开放菱形、棘语者分叉枝纹。
- 只有实际选择改变时触发一次短收放，按职业持续 240–380ms；绘制靴底的 150 像素位置作为缩放原点，不上下漂浮。
- 结束恢复原 1.5 倍卡片尺寸，菜单仍为 1 倍；不保留常驻放大、不增加闲置呼吸或抖动。
- 快速切换立即终止旧补间并归位；反复点击当前职业不重播，不增加对象或堆积补间。退出中途销毁旧肖像/纹章，重入恢复静态。
- 关闭游戏动态反馈，或系统请求减少动态效果时，直接显示静态选中结果，无肖像/纹章补间。
- 肖像与纹章仍无独立交互，只有原整卡背景处理 pointerup。按下不提前选择；选择与返回不写职业存档，开始时才保存一次并进入所选职业。
- 不增加震屏、闪屏或选中声音。

## 保留的失败与实际修正

- `regression-02.txt`：初版让已选肖像常驻 1.56 倍，触犯四档旧「静态 1.5 倍」占位要求。修正生产演出为有限收放、最终回到原尺寸，没有削弱旧断言。`regression-03.txt` 恢复 144/144。
- `checks-01` / `browser-01.txt`：Phaser Rectangle 的 top/bottom 等属性是访问器，浏览器桥未序列化，几何断言拿到 undefined。改为在浏览器内显式记录四条边，原 185–440 范围与卡片边界要求不变。`checks-02` / `browser-02.txt` 13/13；正式冻结运行也为 13/13。
- 原历史自然失败、前轮撞墙夹具失败等保持原样，没有清理、覆盖或回滚用户已有工作。
