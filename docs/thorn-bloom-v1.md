# 棘语者：种荚预期与花冢引爆（2026-10-22）

## 本轮目标与前置状态

上一目标回合属于**progress**：守望者承伤蓄势反击完成，独立正式验证38/38入口、570/570机制检查，四职业首层及整章各4/4；原始记录在`warden-reprisal-v1`。这些是上一轮被冻结源码的结果，不冒称是本轮新源码的验证，也不把自动通关当成人类爽感验收。整体目标「要玩起来很爽」保持有效。

这轮转到已有`thorn_seeds`，把「普攻植种→三层成熟→主动按原技能引爆」的积蓄和兑现变得可见。**不是新增植种机制、免费技能、连锁爆炸、额外AOE或新职业／肖像。**

## 从现状找到的问题

- 原种子是每层4×5的小方块，绘制高度`enemy.y-enemy.hitRadius-14`；普通敌半径14，恰好与精英血条`y-28`重合。截图保留在`baseline/seed-marks-before.png`。该静态夹具暂停了受击闪白，不能用角色颜色差异冒称美术提升。
- 旧提示槽只覆盖掠夺者／守望者，棘语者没有已植种／满种／Q可用状态；种满后继续按住射击很难看出蓄积已到上限。
- 原引爆对每个目标先放通用环形脉冲，再尝试真实命中；被拒绝的伤害也可能出现命中式演出，且圆环容易被理解成新增附近AOE。

## 实现

### 不改变的玩法账目

- 仍然只由**存活目标上的普攻命中**植种，最多3层；技能、DOT、致命命中不补种。
- 仍然每层90%基础攻击，白板10时是9 / 18 / 27；种子结算本来就不暴击，露核1.25仍单次取整为33。没有按新图形半径造成伤害。
- 原技能保持6000ms冷却、100范围220%震退和8枚70%短种刺；三歧仍为主弹10、两侧各5，并能正常植种。
- **保留原本跨距离／隔墙引爆已植种目标的规则。** 新提示不冒充射程／LOS预测；只汇总真实可接受命中的存活已植种目标。若一个已植种目标暂时不接受伤害，原技能仍会消费那份种子，本轮不悄悄改成返还。
- 引爆仍通过原`hitEnemy`结算，一次实际命中正常吸血；标记、满种提示和绘图不造成虚构命中／吸血／伤害。

### 更明确的积蓄与兑现

- 单个复用`marksInk`绘制三枚角形种荚：已填／空槽可区分；三层变金，短暂开芽。位置移到血条右侧，避开上方精英名称与精英蓄压条。不为每名敌人新建Text/Image/Graphics。
- 只有从未满变满时播一次开芽反馈，继续攻击已满目标不重复提示；花掉后重新植满可以再次反馈。
- 原同一个HUD动作提示槽显示「植种 N · 满种 M · Q 引爆」，冷却时显示原剩余时间，触屏改为「技能键」。没有突变／没有可接受命中的种子目标时隐藏；其他职业不共存堆叠。
- 原先通用圆环改为**实际种子造成HP下降之后**的局部破荚碎片，无大面积实心遮罩、无目标间连线、不暗示新增连锁伤害。破荚最大半径48只用于绘图。
- 每次实际引爆批次只播一次独立低频破荚声、一次玩家附近兑现文字，并请求36ms停顿，仍受原55ms上限及90ms节流约束；原击杀／精英命中的停顿不累加为长时间冻结。
- 新满种与引爆PCM为程序合成。模型逐样本比对旧12种音效×四职业，旧声音不变；音频仍走原16 voice上限、静音、可见性和场景销毁逻辑。
- 只清理已消费的旧种荚图形，不等下一帧／打击停顿结束才撤掉。暂停隐藏行动提示，换层清空原标记；无新增资源计时器／永久存档。
