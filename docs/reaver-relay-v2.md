# 血债接力 v2：付费命中限定（历史，已由 v3 取代）

当前规则见 `reaver-relay-v3.md`。本页与 `output/reaver-relay-v2/` 保留中间设计，不是通过报告。

v1 的处决限定在一局自然章节中零触发。v2 改为真实付费追斩命中原目标即可接力；持有分支时，合法伤口目标优先于无伤口的击杀票目标，方向、距离、墙与新按键条件仍保留。普通命中、跳伤、旁目标、失手不传播。

受控浏览器 16/16，旧血棘 24/24、追斩动作 22/22 等定向验证通过。正式套件 **9/10**，260 个冻结文件无漂移。唯一自然样本真实选择血棘刻印 → 血债接力 → 第三次葬礼，确实觉醒并在约 76.04 秒通关；但**仍是 0 次接力、0 次继承支付、0 次继承结清、0 帧接力演出**，按原覆盖要求失败。

来源记录进一步定位：三次实际流血追斩承诺/命中都发生在 Boss 房。普通阶段的「近身有敌优先普攻」提前挡住了追斩候选入口，Boss 房则没有第二个可接债敌人。因此仅放宽处决条件并没有解决正常战斗的可用性。

v3 有意改变了持有分支时的候选许可：真正付费的刀外伤口可以越过近战优先；并不免费给票、增加无敌或自动出刀。该设计变化适用于玩家，而不是只改测试控制器来制造触发。v1/v2 原始失败结果不改标、不与 v3 样本混在一起。
