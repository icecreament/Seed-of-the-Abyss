# 掠夺者：血债接力 v1（2026-10-26，已被 v2 取代）

> 历史设计记录，不是当前规则。自然局发现处决限定导致零次接力，已改为真实付费命中触发；当前规则见 `reaver-relay-v2.md`。原失败证据保持冻结。

## 玩法目标

在既有「种流血 → 付费追斩 → 撕裂结清」之外，让一次成功处决为下一个目标打开机会。不是免费刷新冲刺，也不是自动吸附连杀。

原本所有掠夺者击杀已经会获得 1200ms 的普通追近票，因此本分支不重复添加击杀票。新突变 `reaver_relay`（血债接力 / Blooddebt Relay）前置为 `reaver_bleed`（血棘刻印），通过正常突变选择获得。当前总计十五项突变，其余十四项原文与原机制保持不变。

## 实际规则

1. 必须是原有追斩已经支付的流血，且其**原目标被这次普通攻击的结清伤害实际处决**。旁边敌人的普通命中/处决、环斩、流血跳死、Q、没有杀死原目标、失手或丢失原目标均不接力。
2. 从尸体原坐标寻找 160 中心距离内最近的存活、可命中、没有剩余流血跳数且视线通畅的敌人；距离并列时按原对象顺序稳定选择。墙阻断，已有血债不叠加、不刷新、不覆盖。
3. 接上本次支付的跳数，最多三跳；不继承暴击、过量伤害或原目标的防御倍率，不立即造成伤害。
4. 新血债使用原有流血时钟和原有每跳 30% 攻击计算。首次跳伤在 1000ms，1/2/3 跳分别保留到 1100/2100/3100ms。此处的 100ms 尾部与原流血一致，避免分数帧累加误差吞最后一跳，不是新增第四跳。
5. 下一次追斩仍遵守原有 64 距离移动预算、480 速度、视线、移动/瞄准方向、普攻冷却和松开后重新按下的输入约束。不能穿墙、不自动转向、不额外无敌，不重置 Q 或冲刺。
6. 接力不会自己继续传播。只有玩家再完成一次原目标的付费追斩处决，才可能产生下一次接力。继承的流血跳死敌人不会再传播。
7. 新标记进入原有 marks 生命周期，选择/暂停冻结债务，换层与重开照常清除。结束和死亡后拒绝接力，Boss 胜利不会死后再扩散。

## 外观与可读性

处决到新目标之间用三枚短促的骨红碎刃表示血债的去向，180ms，无大面积填色、闪白或额外震屏。减弱动态时不绘制这段非必要装饰，但原有流血跳数、真实债务和目标提示仍可见。

标记在真实处决时立即授予；飞行短刃只是说明去向的装饰，不是额外实体弹丸，不参与碰撞或伤害。

新目标的「血债接力 ×N」放在更高的一行，避开原目标的撕裂反馈和伤害数字。复用既有受限短效绘制器；每次真实接力的文字使用原有自动销毁的浮字，不新增永久对象、计时器或监听器。

## 已发现并修正的问题

- 初始模型中若直接设置 `bleed = 跳数 × 1000`，17.3ms 分帧可使第三跳残留极小正数，从而只跳两次。已保留最初失败模型与模块，并在生产代码采用原有 100ms 尾部；测试仍严格要求 1/2/3 跳，不放宽期望。
- 首轮浏览器检查最后一项使用了错误的角色贴图名 `strike_reaver_pounce_awakened`，实际为 `pounce_reaver_awakened`。原失败记录保留，仅修正测试引用；第二轮 14/14，实际双追斩的伤害与状态检查不放宽。
- 探索截图中接力与撕裂文字相邻拥挤，生产浮字上移 20 像素；正式捕获使用修正后的版本。

## 初版验证结果（历史）

初版正式结果为 **17/19**，249 个源代码/辅助文件在该次运行中无漂移。六局一次性章节均通关，但旧伤口策略与新接力策略都未拿到第三项环斩，均未触发原有觉醒，因此两项自然门禁按原要求失败。更重要的是：新接力章节虽通关，记录为 **0 次接力、0 次继承支付、0 次继承结清、0 帧接力演出**。这不是可接受的新分支覆盖，不能拿通关代替。其余四职业旧鼠标策略通关，未用来掩盖该缺口。完整旧报告留在 `output/reaver-relay-v1/verified/verification-report.json`；v2 是机制修订与不同选卡路线的新样本，不把这次改标通过。

受控双追斩序列的已验证规则：30HP 的已有流血目标被真实追斩处决；接力时下一个目标保持 100HP；第二次真实移动 + 新 LMB 支付继承的三跳并将其打至 66HP。整段正常时钟，仅两次普攻，实际累计伤害 64（30 + 34），无过程中写血量、位置、标记或冷却。敌人静止、AI/击退禁用、分支与觉醒归属均为明确夹具，不能算自然实战。

新自然策略只把选卡优先级改为「血棘刻印 → 血债接力 → 吞生根须」，其余原可见伤口的移动、避险、Q、冲刺、按下/松开策略不变。只读观察器必须追溯：真实原目标处决 → 合法最近目标继承 → 后续实际支付继承血债 → 同目标实际生命损失。普通普攻重新植血会使观察信用失效，不将其冒充接力收益。单局缺少覆盖会如实失败，不刷局补出结果。

注意：旧脚本对未列入优先级的新 ID 会得到 `indexOf = -1`，因此旧伤口脚本在新候选池里也可能与显式接力脚本作出相同选卡。这两局分别用于旧脚本兼容与新来源追踪，不声称是不同打法，也不合并成独立平衡样本；不是因失败而重跑同一局。

## 手动试玩重点

先拿血棘刻印，再拿血债接力。关注一次撕裂处决后，血红短刃去了谁身上；下一步仍自己选方向、移动并重新出刀。如果目标已经贴身，正常普攻也是选择，不强迫为了追斩刻意退后。

需要真人判断：能否在战斗中看清下一个机会；处决后接下一刀是否顺滑；是否总被近身杂兵挡住追近；以及不拿这个分支的环斩路线是否仍有吸引力。自动通关、模型和截图都不能代替这些反馈。
