# 四职业接触材质与方向 v1

日期：2026-10-26。整体目标仍是“要玩起来很爽”，本轮完成的是一次有限的实战反馈打磨，不是整体手感或人类试玩验收。

## 发现与取舍

现有四职业已有专属动作、招牌连招、敌人受击姿势及音效，不重复添加新系统。真实鼠标固定目标截图显示：普通攻击命中均使用同一个随机朝向的六射线/六亮点火花，只换职业色；在原白色受击填充上，材质与攻击方向都不明确。

本轮替换这一次命中火花，而不是额外叠一层效果。保留原斩弧、招牌演出、音频、数字层次和敌人受击逻辑。

| 职业 | 新的局部接触痕迹 | 普通显示寿命 |
|---|---|---|
| 寄生守望者 | 宽刃压痕、短切面与两片碎屑 | 135ms |
| 掠夺者 | 三道长短不等、顺着真实出手方向的钩状撕痕 | 140ms |
| 影行者 | 细窄的入刃线与一个短交口，不扩大成光团 | 95ms |
| 棘语者 | 两片相连的裂壳边缘与种荚脊线，不画假伤害圈 | 125ms |

暴击寿命增加 25ms、局部尺度 1.12；已确认招牌命中增加 35ms、尺度 1.22。最大寿命 175ms，局部几何半径不超过 26 世界像素（不含描边）。深色细描边保证原白色受击闪烁上仍能读到刀口。

普通近战和主种弹、真实撕裂与原有招牌结算使用新接触图形；其他原技能/持续伤害的通用效果不改。必须先发生真实目标 HP 下降。没有掉血则既不制造新接触，也不播放原通用命中火花。零向量的种子招牌结算仅以施术者到目标方向摆放裂壳，不表示新增弹道或伤害方向。

## 技术与范围

- 新增 `src/ui/ContactStrike.ts`：纯几何函数，按职业/强度/明确战斗年龄产生最多四条折线，不访问游戏状态、时钟、随机或 Phaser。
- 修改 `src/ui/CombatPresentation.ts`：复用原 Graphics 与原 80 个效果上限。没有新增对象、监听、粒子发射器、tween 或定时器。每个已接受接触保留被替换火花原本的一次共享随机数消耗，但实际方向与几何不随机，避免正常命中改变游戏的随机数调用顺序。
- 修改 `src/scenes/RunScene.ts`：只替换已确认命中的展示入口，并让原 CombatPresentation 动态设置同时尊重系统 `prefers-reduced-motion`。此前它只读游戏内开关；该修正也让已有可选震屏/残影遵守系统减少动态效果设置。伤害/判定/碰撞/输入/冷却/成长/音频不改。

舒适或系统减少动态效果时保留静态材质轮廓并淡出，不做碎片位移和裂壳扩张。暂停、原命中停顿、三选一沿用原战斗时钟冻结；恢复后自然消失。跨层沿用原效果容器的短寿命，不声称跨层立即清空；退出场景销毁并清空。

上一轮 313 份冻结输入中仅 RunScene 与 CombatPresentation 有意变化，其余 311 份不变。唯一新增生产模块为 ContactStrike。`output/contact-strike-v1/declared-display-deltas.json` 记录已审阅的七个展示差异块，`audit-scope.cjs` 逆向移除它们后必须逐字节重建两个原文件，包含原 CRLF。其余原逻辑不以“测试碰巧通过”代替范围证明。
