# 远程射手：能看懂，也能主动反制（2026-10-21）

## 为什么做这轮

上一轮首层棘语者低血通关不是远程敌人造成的：首层只生成 crawler。为此新增只读接触诊断，记录敌人类型、有效接触伤害、移动状态和第一次退让时间；不改原控制器策略，也不以增加生命或伤害来抹平结果。

另行隔离检查发现真实可读性问题：普通/精英 spitter 在首次满足条件的 **1ms AI 更新**中就发射；张口亮帧只是循环移动动画的一帧，不代表出招。旧行为记录保留在 `output/ranged-v1/baseline/instant-shot.json` / `.png`。该基线采集脚本拒绝用新行为覆盖旧证据。

## 玩家实际得到的变化

- 射手进入射程且看得到目标后，先站定并展示 **420ms 蓄力**，再发射。
- 短琥珀色方向箭头（72设计像素）、喷口亮点、局部进度条对应真实出招；张口帧只在真正蓄力时出现。
- 开始蓄力就锁定**发射点和方向**，不会看到玩家横移后偷偷转枪。实际弹体从同一喷口坐标发出。
- 普攻等真实击退能打断；仅伤害、没有正击退力度/时长的命中不能凭空打断。重整420ms后还需完整展示下一次420ms蓄力。
- 横移即可躲开已承诺方向，不把冲刺无敌设成唯一解法。已发出的弹体仍然危险，杀死射手不消弹。
- 打断只有局部命中反馈和「打断 / DENIED」，不额外送伤害、回血、击杀或冷却返还。

## 保留与边界

- 普通1400ms、精英1100ms为包含蓄力的名义周期，不是再额外增加420ms。发射后冷却分别980/680ms；实际帧边界、击退与视线仍会影响实战发射时刻。
- 血量、伤害、速度、射程、弹速、弹体墙碰撞、玩家属性和碰撞盒不改。开始时需要原射程，蓄力中目标离开射程不导致偷偷重瞄。
- 失去视线或目标隐身取消本次，180ms后才允许重新展示完整蓄力。死亡/清场永久取消排队射击和提示。
- 暂停、融合、顿帧不推进蓄力；长帧不能同一更新开始又发射。
- 不加全屏激光/震屏/闪白，不全局限制射手数量。隔离压力检查测量28只同时蓄力、事件/音频有界；并不等于宣称28只对真人体验良好。
- 提示通过原HUD让位通道保护视野；沿用限流的 tell 音色，无新增音频依赖。
- 诱饵、根槌精英和Boss既有机制不改，四职业白板均保留普攻打断路径。

- `scripts/check-ranged-model.cjs`：10项纯模型检查，含10000个方向样本。
- `scripts/check-ranged-browser.cjs`：18项隔离真实引擎/键鼠/触屏检查。明确放置实体的测试不是自然实战。

### 影行者后续诊断（独立记录，不是重试刷绿）

在确认整章进程以失败码1结束后，为整章脚本增加只读伤害溯源。包装原接触回调与 `applyDamage`，每次原调用只执行一次，保留原返回值；不改生产代码、操作策略、冷却、随机数、生命或伤害。原始经过验证的脚本用完全匹配旧SHA256的快照保存为 `suite-snapshot/check-chapter-natural.cjs`，汇总脚本只允许这一明确的测试辅助文件解析到快照，生产文件有变化仍直接失败。

只追加一局全新影行者诊断，输出到独立的 `shade-diagnostic/`，没有覆盖原局。仍在第三层死亡：56.19s、52击杀。记录到14次接触和1次弹体伤害，分别实际减少138HP和6HP（期间有换层/精英击杀回血；致死过量伤害不冒充实际血量损失）；最后由精英crawler接触致死，根槌砸地伤害为0。因此不能把这次死亡笼统归结为“远程弹太多”。

另一个原生Arcade隔离几何扫描 `audit-contact.cjs` 证明自然控制器的固定39px中心距避让存在盲点：普通和放大精英的矩形身体都存在中心距大于39但仍被原生物理判为重叠的位置。该扫描只测几何，不伪装为自然打法，也不能反推每次历史伤害的原因。夹具先前在暂停的新实体上漏刷新缩放后的body边界，随后显式 `updateBounds()`；未改生产碰撞体。

本轮保留近战接触风险作为待解决问题，不通过加血、降伤、偷偷扩大无敌时间，或改控制器后将原失败局改写成成功。追加诊断的失败也完整保留在 `shade-diagnostic.txt` / `shade-diagnostic-summary.json`。
