# 掠夺者：血债接力 v3（2026-10-26）

## 为什么不沿用前两版

v1 要求付费追斩处决，v2 放宽到付费命中，但各自的新自然样本仍为零接力。通关不等于这条路线有用。来源证据表明，普通战斗的近战优先把追斩入口挡住，付费追斩只在没有第二个敌人的 Boss 房发生。

v3 不再只加伤害回报，而是允许拥有这条分支的玩家在近身有杂兵时，主动选择刀外的伤口目标追斩。**这是一项真正的追斩候选许可变化，不能描述为所有旧授权条件不变。**原方向、移动、视线、射程预算、付费、新按键与受伤规则保持不变；没有免费票或新无敌。

## 当前玩法

- 新突变 `reaver_relay`「血债接力 / Blooddebt Relay」，前置 `reaver_bleed`。总数仍为十五项，其他十四项突变原文不变。
- 持有分支时，刀外合法伤口优先于无伤口的击杀票目标；即使近身有敌，只要原移动/瞄准/距离/视线条件全部满足，也可主动支付这份流血发动追斩。无伤口的击杀票不能越过近战优先；撤退、错误朝向、原有长按也不能借此追近。
- 原目标实际受到这刀的普通攻击结清伤害后，不论是否死亡，为源点 160 范围内最近、无剩余流血、存活可命中且视线通畅的另一目标接上最多三跳血债。并列顺序稳定，不覆盖已有债，不立即造成伤害。
- 接债是立即授予标记；三枚骨红短刃是 180ms 去向装饰，不是碰撞弹丸或另一段自动攻击。减弱动态关闭装饰，但流血跳数与目标信息仍在。
- 继续使用每跳 30% 攻击和原时钟：首次 1000ms，1/2/3 跳保留至 1100/2100/3100ms。原有 100ms 尾部避免分数帧吞掉最后一跳，不产生第四跳。
- 后续仍需自己选择：再支付血债追斩，或让它按原时钟跳伤。普通普攻、环斩、跳伤、Q、旁目标与失手不会自行接力，不会自动连锁整屏。
- 普攻冷却、64 距离移动预算、480 速度、墙体碰撞、接触伤害不变。原玩家/敌人是 overlap 而非实体推挤，本次没有修改其物理配置或增加穿透/无敌。
- 暂停/选择冻结标记与短效战斗时间，换层/重开按原生命周期清除；结束/死亡后拒绝接力，致死 Boss 不再死后转移。

## 构筑与外观的真实取舍

本次自然样本固定选择血棘刻印 → 血债接力 → 第三次葬礼，第三项真正取得原有觉醒和环斩，牺牲共享吞生续航。也可以第三项选续航，但那条路线并未获得原有觉醒，不能强行要求其觉醒或免费补给外观。

接力文字与原撕裂/伤害反馈上下错开，避免挤成一团。每次接力仍只有原来的那次普攻；不额外回血、增加攻击次数、重置 Q 或冲刺。实际继承的跳伤/结清伤害照原命中规则计算。

### 单独的手动拉距打法样本

在生产代码完全不变的情况下，另声明一种不同的输入策略：优先有可见流血的目标，普攻恢复时拉至近战边界外 24 距离，之后前进并重新出刀；准备血债时松开长按，非低血量时先不用 Q 清掉目标。保留原避险评分、墙导航、冲刺、90ms 采样、正常时钟与全部原断言，不写血量、位置、标记或冷却。

这一局约 129.30 秒通关，**真实接力 1 次、接力绘制 14 帧，但继承血债后续支付 0 次、后续结清 0 次**。所以该补充样本也按完整链路要求失败；不是“终于全通过”，也不与旧策略合并成多局成功率。

唯一真实事件发生在第 3 层约 62.31 秒：支付 2 跳的原目标从 10HP 处决到 0；最近合法新目标接上 2 跳，继承瞬间保持 29HP，授予标记前后总伤害不变。独立审计复核了原目标、真实支付、最近目标、视线、160 范围、2100/1000ms 时钟与零即时伤害。但没有证据证明下一刀接上了它。

### 下一轮应做什么

不要继续改数值碰运气，也不要重跑相同策略求绿。优先给继承血债一个**持续、可与普通流血区分的目标标记**，再核对恢复期拉距、前进与新按键的时机。当前 180ms 去向短刃和短浮字不足以持续指出“债在谁身上”，普通伤口又会和继承伤口竞争目标；这是需要实际验证的下一项，而不是已经证明的唯一原因。

当前审计：`output/reaver-relay-v3/partial-audit.json`；原失败门禁：`verified/verification-report.json`；独立打法及失败原件：`manual-practice/play/chapter-playchecks.json`、`manual-practice/console.txt`。原章节与补充章节录像均保留。v1/v2 的所有失败原件不改写。

新增浏览器检查明确覆盖：原目标存活的实际付费命中也会接债；近身杂兵不能阻止有真实伤口支付的选择；无伤口的击杀票不能绕过；撤退不能绕过；长按不会自动移动或支付远处血债；没有额外无敌。原实际双 LMB 追斩捕获仍保留，30HP 源目标被处决，下一目标接力瞬间保持 100HP，第二刀实际结清到 66HP。

自然验证要求真实原目标付费生命损失、最近合法继承、真实绘制，以及后续真正支付并命中继承血债的同一目标。普通普攻重新植血会使观察信用失效；不会把普通新伤口当成接力收益。如果没有覆盖仍按失败记录。

## 手动试玩

先拿血棘刻印和血债接力；对已带伤口的刀外目标主动朝向并移动，松开再按普攻。近身的杂兵不再无条件阻断这次有支付的选择，但仍可能受到接触攻击，也仍可能失手。留意血红短刃把债交给了谁，再决定继续追还是回身解决近敌。

还需要真人验证：这种主动切目标是否顺手，能否读懂下一步机会，是否会意外越过自己想砍的近敌，以及选择环斩觉醒而非续航是否值得。受控演示和自动通关不代表这些已验收；整体「要玩起来很爽」仍未完成。
