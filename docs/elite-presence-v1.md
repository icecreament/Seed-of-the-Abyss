# 根槌精英：可读的蓄势与反打 · presence v1

日期：2026-10-24。目标是让强敌的身体动作与真实战斗阶段一致：**扎稳 → 举锤 → 落锤或被破招 → 低身露核 → 起身**。不是新增技能，不是靠更多粒子制造“更爽”的假象。

## 为什么做这轮

修改前的真实引擎静态阶段截帧中，蓄力前半、蓄力末端和落锤时缺少身体动作区分；破绽期间一直使用同一张张胸纹理。原精英文字、HP 和压力/破绽条还覆盖头部。玩家只能主要依赖圈与文字判断时机。

`output/elite-presence-v1/baseline/` 保存了修改前的实际 POST_RENDER 截图、状态与原始纹理 RGBA 哈希；不是重新绘制的“旧版示意图”。基线脚本为暂停引擎手动推进真实 AI delta 的受控美术状态样本，不是自然战斗录像，且没有消费落锤伤害事件。

## 实际改动

- 新增 `RootHammer.ts`：原生代码像素绘制六个 32×32 动作单元，使用实际旧重怪/露核重怪的底稿。动作图集 `enemy_root_hammer` 为 192×32、nearest 过滤。
- 新增 `EliteHammerStance.ts`：只读既有 `EliteDuel` 的阶段、剩余时间、压力；没有新增动作时钟，也不反向写入 AI。
- `Enemy.ts` 在根槌精英的实际蓄力/破绽阶段选动作，其他阶段恢复旧行走动画。六个单元分别为扎稳、举锤、落锤、低身露核、破招失衡、露核起身。
- 新动作不加入普通受击姿态表，避免轻微挨打把举锤、落锤或露核信号覆盖。破招显示失衡，不冒充已经砸下去。
- 原脚部像素区域保持逐像素不变；原点、缩放、碰撞体、物理位置、生命与攻击数值均不因动作切换改变。
- 文字底端移至角色 y−78，HP 条顶部 y−72，压力/破绽条顶部 y−64。精英原有 2.4 倍缩放下，身体矩形顶部为 y−57.6，元信息不再穿过脸。
- `eliteOverlayBounds` 合并实际翻译后的文字边界与当前血条/阶段条边界。`RunScene.updateHudFocus` 将其按既有相机/HUD 投影加入保护区；不再只保护身体与蓄力圈。破绽/待机时即使没有预警圈，HUD 也让位。只改变原 HUD 的透明度，不移动按钮或改变命中区。
- 终止后的 duel 不再重新显示标签；死亡、停战、重开清理相关姿态与元信息。

## 时间与机制边界

`EliteDuel.ts` 完全未修改，仍为：

| 项目 | 原有值（保留） |
|---|---:|
| 初次准备 | 700ms |
| 蓄力 | 1050ms |
| 自然落锤后破绽 | 900ms |
| 被破招后破绽 | 1250ms |
| 后续冷却 | 2400ms |
| 落锤半径 | 94px |
| 接战距离 | 130px |
| 破绽承伤倍率 | 1.25 |

全动态时，实际蓄力的前 40% 显示扎稳，后 60% 举锤。自然落锤后的前 120ms 显示落地；破招则对应失衡。之后低身露核，剩余 180ms 时起身，但**这 180ms 仍然能吃到原有破绽增伤**。不为了展示全动画而延迟玩家破招。

关闭动态反馈或系统请求减少动态效果时，保留必要静态信号：蓄力举锤、破绽露核，不进行阶段内换姿。伤害、压力、时间、范围与增伤不变。没有新增闪屏、震屏、光环或音效。
