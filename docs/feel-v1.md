# 战斗手感第一轮（2026-10-21）

## 目标与边界

把现有四职业的操作响应、技能回报、命中/击杀反馈和战场接敌节奏打磨到可供试玩的状态。测试通过表示相应机制有证据，不表示主观爽感或整章平衡已经得到证明。

## 已落地

- 攻击/冲刺 140ms、技能 160ms 输入缓冲；按下攻击与持续按住分开处理。
- 职业收益：守望者壁垒即时震退伤害；掠夺者血涌增伤与攻速；影行者落点后破隐重击；棘语者近身新星爆发和更快实弹。
- 命中停顿、独立程序化音色、连斩、残骸和碎片；特效与音频有数量上限。
- 初始八敌、围绕玩家生成、450ms 出场预警；共享寻路绕柱，远程敌人检查视线。
- 连续弹道碰撞，避免高速度/跨帧穿墙和漏判。
- 受击保护间隔 350ms；触屏无手动瞄准时可自动朝可见敌人射击。
- 音量/静音与舒适镜头选项持久化；暂停、三选一、失焦与离场正确管理战斗和音频生命周期。

## 未验收/下一步

- 整章正常速度通关、Boss 难度曲线及多轮构筑平衡，不能由首层测试替代。
- 音色是否耐听、击杀是否真有爽感，需要人工试玩判断。
- 世界边缘角色与底部 HUD 的遮挡关系需要单独处理。
- 建议先打磨一个职业的完整体验样板：可见进化、能改变操作的突变组合、有辨识度的精英与 Boss 破招反馈，再横向推广；暂不堆更多职业与章节。
