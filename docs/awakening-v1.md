# 四职业一阶觉醒（2026-10-21）

## 目标

让「选到核心突变」变成看得见、打得出的成型时刻，而不是额外叠一层永久发光。职业肖像、战斗精灵、实际突变演出使用相同的材质和识别轮廓。保留像素风、最近邻采样、原始画幅和脚底锚点。

| 职业 | 已有触发突变 | 觉醒称号 | 外观与实际触发演出 |
| --- | --- | --- | --- |
| 守望者 | 荆冠领域 `warden_thorns` | 荆冠守誓 / Thornsworn | 根肩、骨冠和骨甲；壁垒真实领域脉冲时展开六根骨刺 |
| 掠夺者 | 第三次葬礼 `reaver_cleave` | 赤刃葬礼 / Crimson Requiem | 刃状肩棘、血脉和背刃；第三次普攻才打出三段断裂刃轮 |
| 影行者 | 无声处刑 `shade_ambush` | 无声王刃 / Silent Sovereign | 裂冠面甲、分叉披风；真正消耗隐身的破隐攻击打出双线裂斩 |
| 棘语者 | 寄生花冢 `thorn_seeds` | 寄生花冕 / Gravebloom | 枝冠、金色种荚、寄生花甲；实际引爆有种子的目标时开五瓣花 |

- 通用突变、另一个职业专属突变均不偷开觉醒。
- 每局只在首次激活时播放一次短促展开和称号横幅；不新增选择层、强制停顿或全屏闪白。
- 三选一卡片提前显示觉醒肖像和双语称号；生命面板使用独立 128×160 肖像，不再把小战斗精灵放大充当肖像。觉醒后肖像同步更新。
- 形态覆盖全部 14 帧 / 五种姿态。保持原有移动、普攻、冲刺、受伤、技能染色和残影逻辑；换形不重建 Arcade body。
- 原生命、伤害、暴击、冷却、突变掉落/候选、伤害范围、技能时机和碰撞大小全部不变。觉醒不是免费加成。
- 新局恢复基础形态，不写永久存档；旧存档无需迁移。

## 可读性与生命周期

- 新增轮廓使用骨、木、暗布、血金属的实体色块，不靠大范围泛光。
- 专属演出采用断开的线条，避免实心圆盘遮挡怪物和 Boss 预警；沿用全场 80 短效上限。
- 所有演出年龄只由战斗 delta 推进。暂停、三选一和结束期间不会推进。
- 觉醒展开不新增震屏/闪屏；已有震屏仍服从舒适设置。
- 肖像和称号加入现有 HUD 让位通道；生命数值、生命细条和触控命中区域不变。
- 肖像保持在原 54×66 槽内，实际显示为 51.2×64。称号放在生命条下方右侧，避免覆盖生命与击杀数。

## 实现

- `src/data/awakenings.ts`：触发映射、双语称号、形态键。
- `src/assets/HeroAwakening.ts`：前后两层代码原生像素绘制，复用原角色材质。
- `src/assets/PixelFactory.ts`：增加四套 448×32 觉醒图集、四张 128×160 肖像、五姿态动画。
- `src/entities/Player.ts`：视觉换形，不更改战斗状态；保留翻转、动画帧与暂停状态。
- `src/scenes/RunScene.ts`：真实融合触发、卡片预览、HUD 联动、真实突变事件的演出调用。
- `src/ui/CombatPresentation.ts`：骨刺、刃轮、裂斩、花开；统一数量限制和战斗时间。

## 验证入口

- `npm run build`
- `npm run test:regression`：新增触发隔离/新局重置、14 帧无越界/脚底不变/确定性；原动画门禁扩展到基础和觉醒共八套，仍逐姿态验证。
- `npm run test:awakening:browser`：真实融合键盘/触屏、形态与肖像、属性/物理不变、五姿态、移动/冲刺/技能输入、真实突变事件、暂停/舒适/上限、双语布局和四倍率。
- `npm run test:chapter:natural`：正常速度、全新浏览器存档、只发送输入的整章控制器；新增只读外观观测，每次观测校验拥有的突变与图集/肖像一致，并要求真正经过觉醒。

证据目录为 `output/awakening-v1/`。`awakening-comparison.png` 是绘制素材对比；`*-choice.png` / `*-awakened.png` 是隔离界面截图；`chapter-playtests/` 才是自然整章证据，不混用。

## 验收边界

此版本是一阶可见进化，不是分支装备、第二阶形态或新职业。视觉变化不保证每个人都会觉得更帅；自动输入成功也不是主观爽感结论。触屏检查是浏览器模拟，不等于安卓/iOS 真机验收。
