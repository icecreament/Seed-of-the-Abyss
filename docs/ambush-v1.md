# 影行者破隐清弹（2026-10-21）

## 来源：保留真实失败，不靠重跑掩盖

HUD 让位完成后的正常速度整章测试中，影行者在第 3 层、约 77.36 秒死亡。失败录像显示追击近处敌人时敌弹逐渐累积；这既暴露了近战切入的压力，也受自动控制器目标策略影响，不能直接等同于人工玩家体验。

## 实际规则

- 仅影行者**消耗暗影步隐身的那一次攻击**清除落点 110 半径内、有墙体视线的有效敌弹。
- 暗影步位移期间不提前清弹；落地后的第一次攻击才执行。普通攻击没有永久弹盾。
- 不影响友方弹、超过半径的敌弹、隔墙敌弹、Boss 地刺与冲锋预警。
- 不附加伤害、击杀、回血或冷却返还；原 220% 破隐伤害与冷却不变。
- 只有真正清到敌弹才出现局部紫色碎光、破弹数量、24ms 封顶顿帧和独立原创合成音色。服从既有视觉/声音上限与舒适设置。
- 暂停和结束不消费攻击或演出；存档不新增字段。
