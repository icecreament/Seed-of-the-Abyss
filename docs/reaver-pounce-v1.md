# 掠夺者：压肩扑杀与落刀身体动作 · pounce v1

日期：2026-10-24。继续「要玩起来很爽」，让掠夺者不是一边滑行一边复用通用冲刺，而是用自己的身体语言表达承诺追杀：**压肩收刀 → 贴地扑近 → 钩刃劈入 → 低位带过 → 回收 → 归势**。基础与觉醒各有完整六格。不增加闪光、粒子、泛光或屏幕演出。

## 改前断层与实际基线

开始前读取上一轮独立迎击补充的 177 份源文件指纹，全部精确一致。当前工作树已有大量其他改动，原样保留，不重置、清理或提交。

改前正常引擎录帧：明确击杀一只夹具敌人获得原追猎票，随后真实 D＋鼠标新按下，承诺 50px 距离预算；物理推进后实际消费落刀，原伤害 19，原第三层重怪 HP 86→67。英雄只显示原 `hero_reaver` 的通用 dash12 与 attack8→9→10→11。录帧在 `output/reaver-pounce-v1/before-physics-resumed/`，同时在非战斗菜单读回完整 25 套既有图集的 RGBA。

这不是自然局：赚票使用明确夹具击杀、目标固定不行动；觉醒捕获也只是外观夹具。净位移和墙钟时间仍受原物理帧/键盘采样影响，不把不同次采样冒充逐帧对齐的随机对照。

### 保留的初版夹具问题

初版 `before/` 录到了追猎开始，却没有物理推进。原因是夹具的击杀调用原命中停顿暂停了物理，随后夹具直接把 hitStop 归零，绕过了原自动恢复分支；并不是追猎生产代码卡死。修正夹具同时恢复原物理与动画暂停状态后，才取得上面有实际落刀/19点伤害的基线。初版原始 PNG 和 JSON 保留，不覆盖、不拿它当美术改前样本。

## 仅从已承诺的真实状态取姿态

新增 `src/systems/ReaverPounce.ts`：

- 扑近 0/1 两格直接取原 `ReaverPursuit.travelLeft` 的前/后半段，包含距离已走完、等待 Scene 消费的末点。新公开的 `travelRemaining` 只读，ReaverPursuit 完整旧源码除这个 getter 外精确相同。
- 劈入/带过/回收/归势是 2/3/4/5 四格，直接均分原 `attackPoseTimer`。基础 250ms；快攻夹具 100ms；真实狂暴快攻夹具仍按原规则变成 80ms。没有第二个计时器或额外前摇。
- 只有原追猎确实消费出刀，且同一 update 内原 `tryAttack` 接受该方向攻击，才接入落刀姿态。一次性视觉交接标记在拒绝、取消和下一次实体 update 清掉，不授权新的攻击、不吞原按键，也不让下一次无关普攻冒充追斩。
- 姿态表示**追猎已经承诺、落刀已经提交**，并不是「原伤口一定成功兑现」。实际付费后落空也照常出刀，原伤口不退款、不转移、不补命中。

原伤害、暴击、狂暴倍率、回血、攻速、CD、方向、最大距离、固定步预算、碰撞、无敌和输入规则不变。RunScene 整个文件与上轮完全相同。新绘制只调精灵姿态和朝向；途中转瞄不让身体反向，也不改变原承诺路线或落刀方向。

## 身体而不是外圈更亮

- `pounce_reaver` 和 `_awakened` 是独立 **192×32，六格，最近邻**图集。原 25 套英雄/觉醒/肖像/敌人/棘语收掌/守望者重斩的全 RGBA 保留。
- 压低肩膀、夹紧异化手臂、撑开承重脚，再由双臂带动钩刃。躯干/承重区域的像素确实变化，不只把武器旋转一下。
- 觉醒层沿同一姿态移动，保持面具与异化肩轮廓，不额外画一把悬空的仪式刀。途中觉醒/回退保持实际同格和剩余期限。
- 所有 12 张基础/觉醒格扩大绘域检查无 32px 单元外落笔；双靴 y28 落点不变，绘制不向靴底下扩展。不用漂浮或扩大物理体积假装扑杀。

## 原优先级与清理

原受伤格保持优先，但不暂停真实追猎移动或原攻击时钟。原无敌拒绝的伤害不取消；真正新受伤、冲刺、技能、死亡、选项、换层与战斗结束清理旧姿态和视觉交接标记。暂停和实际命中停顿冻结原状态，不使用全局计时器或补播。

舒适模式与减少动态采用原英雄姿态，原追猎和伤害照常发生。中途关闭动态恢复对应原普攻格和原攻速，不从第 0 格偷偷重开 250ms。短距离或长物理帧可以自然跳过某些视觉格，绝不为了让六格全部可见而放慢移动/增加停手。
