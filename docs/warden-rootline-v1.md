# 守望者：裂根回击 v1

## 目标与玩法

让守望者的蓄势反击不只是在贴身时加一个数字：挡住一次真实攻击、重新按下普攻后，可以把这一刀送到前排之后，给玩家一个“挡住 → 找射线 → 反打”的选择。

这是一条新增的局内构筑路线，不是单纯换色。`warden_rootline`（裂根回击 / Rootline Reprisal）必须先获得 `warden_thorns`（荆冠领域）；仍通过原有突变选择卡获得，不新增免费入口。

### 实际规则

- 只在原有 `Player.tryAttack` 接受的、真正消耗蓄势的守望者反击后发射。长按、被拒绝的输入和无蓄势普攻不发射。
- 根刃继承**本次反击已经计算完成的整刀伤害**，包括原来判定的暴击与蓄势，不再次掷暴击。初始“只发送蓄势加成”的想法已放弃，避免做成几乎没有价值的弱小附赠。
- 原来的近战照常结算；同一刀实际损失生命的近战对象会进入根刃排除集合，不被这条根刃二次结算。
- 新增命中是次级伤害，不是额外普攻，不增加攻击次数、不种标记、不补蓄势、不附带击退。
- 速度 560 像素/秒，中心最多行进 280 像素，半径 8。敌人的身体半径参与接触判定，因此不能把 280 描述成敌人中心的绝对最远距离。
- 按沿途碰撞顺序贯穿敌人。墙按根刃厚度膨胀，墙优先于同刻敌人接触；长帧也不能穿墙。
- 按原有战斗时间推进。暂停和命中停顿遵守现有时钟；开选择、换层、死亡、结束、场景关闭时清理。
- 最多同时 4 条，与原有弹丸合计不超过 180。使用一个复用 Graphics，不为每条根刃建立对象或计时器。
- 减弱动态时保留必要的骨白轮廓弹体，只关闭非必要拖尾；不能为了舒适模式让危险/命中实体隐形。

## 自然实战的验证方式

新增一个明确独立的输入策略，不篡改旧策略：优先真实选择荆冠领域 → 裂根回击 → 共享续航；获得蓄势且拥有该分支时，优先瞄准近战范围之外、260 像素以内、视线通畅的敌人，允许在这个距离重新按普攻。其余格挡提示、移动避险、Q 与松开/重新按下的逻辑沿用原守望者策略。

观察器只记录原函数一次调用的结果，以及真实 POST_RENDER 中的根刃；不改血量、位置、敌人、技能冷却或时间。必须看到真实格挡收益、付费反击、根刃画面与近战范围外的实际生命损失，不能用受控场景截图替代。

## 后续仍需要人来判断

自动检查只能证明“有这条玩法且规则正确”，不能证明有多爽。还需要真实游玩判断：能否看懂选卡、能否在压力下找准射线、格挡成本与远程收益是否值得，以及触屏实机是否顺手。整体目标“要玩起来很爽”仍未验收。

## 手动试玩建议（不是自动验收结果）

1. 选守望者正常开局，第一次融合拿「荆冠领域」，后续出现「裂根回击」时选它；第三次在续航与冲刺震地之间按自己的习惯取舍。
2. 遇到可读的敌人起手时开 Q 壁垒，确认实际挡住了伤害、出现蓄势提示；持续长按不是这次反击的授权，需松开再按。
3. 先试贴身反击，观察同一个近身对象不会被根刃二次打伤；再试瞄准一条线上更远的敌人，感受是否真的多了一个位置选择。
4. 在墙边和减弱动态模式各试一次：墙必须阻挡，必要的弹体必须仍看得见。

重点收集三条反馈：**能否自己发现怎么用、挡住后的这一刀是否值得、需要瞄准时会不会反而打断节奏**。不用先讨论新职业数量。

推荐的后续顺序：先根据这条路线的实测收敛读感与收益，再给掠夺者和影行者各补一个改变决策的构筑分支；最后用更有意图的敌人组合检验四职业，不先堆新楼层、光污染或单纯加血量。
