# 第一章：枯冠根庭（2026-10-21）

## 当前可玩流程

`选择职业 → 普通层 1 → 突变三选一 → 普通层 2 → 突变三选一 → 普通层 3 → 突变三选一 → 枯冠母体 → 通关 / 死亡 / 撤离结算`

- 普通层保留原先的节奏：存活 45 秒或完成 `楼层 × 12` 次击杀，满足任一即可推进。
- 每次融合后恢复 20% 最大生命；清除上一层残余敌人、弹体、流血与种子标记。
- 新一局不继承任何突变、Boss 状态、诱饵或临时标记。原永久天赋、语言、视频设置和存档保留。
- 没有新增在线依赖、付费图片服务或位图下载。Boss 也是本地代码绘制像素素材。

## 四职业战斗演出

`src/ui/CombatPresentation.ts` 统一管理额外演出，和既有 14 帧职业图集、斩击/光环动画叠加。

| 职业 | 演出识别 |
| --- | --- |
| 守望者 | 青色重型弧斩、棱角根冠、壁垒展开与震地 |
| 掠夺者 | 双层血刃弧线、血涌冠环、流血标记与环斩 |
| 影行者 | 紫色穿刺轨迹、冲刺残影、破隐冲击和蜕影诱饵 |
| 棘语者 | 绿色枝状施法轨迹、实弹分叉、植种标记与孢子爆发 |

- 暴击有独立碎光和轻微震屏；受伤通过实际伤害事件触发反馈。
- 新演出只用战斗 delta 推进寿命，因此暂停/选择期间不会偷偷消耗。
- 演出数量上限：80 个短效、18 个残影；全场弹体上限 180。
- 玩家向场景发送真实触发的 dash/skill/hurt 事件，而不是 UI 凭按键猜测是否成功释放。

## 12 种局内突变

候选池为当前职业 2 种专属 + 4 种通用。每轮无重复、不出现已拥有项；只要还有未拥有专属，候选中保证有一项。总共融合三次。

| ID | 名称 | 实际机制 |
| --- | --- | --- |
| warden_thorns | 荆冠领域 | 壁垒期间每 0.6 秒对 110 半径内敌人造成 65% 攻击伤害 |
| warden_ram | 破城骨槌 | 普通冲刺后首次普攻附带 120 半径、100% 伤害震地 |
| reaver_bleed | 血棘刻印 | 普攻附加 3 次每秒 30% 跳伤；重击刷新持续时间，不叠无限层 |
| reaver_cleave | 第三次葬礼 | 每第三次普攻追加 110 半径、90% 伤害环斩 |
| shade_ambush | 无声处刑 | 破隐攻击必暴；击杀返还 0.4 秒冲刺 |
| shade_decoy | 蜕影替身 | 暗影步在出发点留下 2 秒诱饵，普通敌人真的改变追踪目标；Boss 不受诱骗 |
| thorn_seeds | 寄生花冢 | 普攻/分叉弹植种，最多 3 层；新星引爆所有存活目标，每层 90% 伤害 |
| thorn_fork | 三歧脊枝 | 两枚侧向实弹各造成 50% 伤害，也能植种 |
| shared_feast | 吞生根须 | 每次击杀恢复 3 HP |
| shared_haste | 循环腺体 | 每次击杀返还技能、冲刺各 0.35 秒 |
| shared_dash | 蜕壳爆裂 | 普通冲刺落点产生 100 半径、75% 伤害爆裂；暗影步不冒充普通冲刺 |
| shared_spite | 逆生骨刺 | 受到实际伤害后，100 半径反击 80% 伤害；1 秒内不可重复触发 |

- 数值按整数伤害向下取整，最低 1 点。
- 用实际有效伤害统计总伤害与吸血，不把过量伤害计入收益。
- 突变带来的伤害不会递归触发普攻植种/流血，从而避免无限触发链。
- 界面支持鼠标、触摸、数字键 1/2/3；选择期间冻结物理、AI、冷却、飞行弹体和楼层计时。
- 中文/英文描述都在本地；触屏描述字号放大。

## 枯冠母体

`src/entities/ChapterBoss.ts`：1150 HP，低于或等于 50% 进入二阶段。正常近战、实弹、新星和突变均能命中 Boss；免疫击退以避免无限硬直。

1. **根槌冲锋**：1050ms 锁定方向的长条预警，随后 700ms 冲锋；可以横向移出或用冲刺无敌穿过。
2. **地刺绽放**：1150ms 圆圈/进度预警后判定一次伤害；一阶段 3 圈，二阶段 5 圈，目标圈不会因边界夹取而重叠成相同圆心。
3. **孢子弹幕**：950ms 母体周围的蓄力预警，然后发射 12/16 向可见实弹，墙体会阻挡。

- 一阶段每 3100ms 发起一个图案，二阶段每 2400ms。
- 独立像素骨冠、肋甲、根足与胸腔核心；顶端显示名字、阶段和真实生命条。
- Boss 房使用同一物理墙体组重建碰撞与对应烘焙地面，不残留普通层柱子。
- 战场位于世界坐标 x=512..1280、y=384..832；相机固定在 (896,608)，将战斗区域置于顶部 HUD 和底部技能卡之间。
- 不在暂停、融合或结束时更新 Boss 的攻击计时。胜利只触发一次。

## 结算和兼容

- `RunMetrics.outcome` 为 death / abandoned / victory；老调用缺省仍按 death 处理。
- 胜利获得额外 100 **基础**精华，仍受原永久精华加成影响。
- 死亡才增加死亡计数；撤离和通关不增加。同帧死亡优先，避免致死后壁垒脉冲或飞行弹误判通关。
- 通关/撤离使用独立文案，结果页展示本局三项构筑。
- 原有 `deathSettled` 防重复保护覆盖新结果。旧存档不需要新版本迁移字段。
- 重开、退出时解绑融合键监听并销毁演出/面板，避免同实例复用时叠加。
